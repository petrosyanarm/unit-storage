# UnitStorage App

Modern admin dashboard built with React and TypeScript.

## Tech Stack

- React
- TypeScript
- TanStack Query
- Tailwind CSS
- React-hook-form

## Features

- Protected Routes
- Data Fetching
- Validation
- Responsive Design

## Installation

```bash
npm install
npm run dev
```
